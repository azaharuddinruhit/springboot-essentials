# Spring Boot Essentials Project

This repository is a **template Spring Boot project** designed to demonstrate advanced skills and best practices with Spring Boot. It brings together a range of commonly used features and integrations, making it a great starting point or reference for real-world applications.

---

## ✨ Features

✅ Spring Boot 4.0.0
✅ Java 25
✅ Gradle build system
✅ RESTful API design  
✅ Spring Data JPA with H2 / PostgreSQL  
✅ Redis integration (Lettuce)  
✅ RabbitMQ messaging  
✅ Exception handling with `@ControllerAdvice`  
✅ DTO pattern and ModelMapper / MapStruct  
✅ Unit tests with JUnit 5 and Mockito  
✅ Integration tests with Testcontainers  
✅ Swagger / OpenAPI documentation  
✅ Profiles for dev, test, prod  
✅ Security (Spring Security + JWT)  
✅ Docker-ready setup

---
